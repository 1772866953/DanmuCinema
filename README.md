# 弹幕影院 · DanmuCinema

Windows 原生 GUI 控制台，配合 Jellyfin 提供局域网视频直放与弹幕。视频不经过控制台中转。

## 启动

从源码首次安装，在项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-components.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

组件安装脚本会下载并校验固定版本的 Jellyfin 和 Danmu 插件，需要联网。安装完成后双击 `Start.cmd`，或直接运行 `bin/DanMuLAN.exe`。`Start.cmd` 可以在可执行文件缺失时先构建。

Jellyfin 位于 `runtime/jellyfin`，弹幕插件位于 `data/jellyfin/plugins`。默认视频目录为 Windows 当前用户的 Videos 目录，可以在首次设置中修改。

本仓库发布控制台、弹幕适配器的源代码与安装脚本，不包含视频、运行数据库、账号凭证、API 密钥和第三方二进制组件。项目与 Jellyfin 配合运行，没有修改 Jellyfin 服务端源代码。

## 首次使用

1. 在 GUI 的「首次设置」点击「启动服务器」。首次启动创建数据库，可能需要约一分钟，等待操作完成。
2. 填写管理员账号、密码，点击「初始化 / 登录」。密码至少 8 位。记住这组账号，iPad 也使用它登录。控制台不保存密码，登录凭证使用 Windows 当前用户加密。
3. 选择视频目录、媒体库名称与类型，点击「添加媒体库」。电影与电视剧/动画应分别添加；同一个目录不能重复添加。
4. 在「连接 iPad」选择真实局域网网卡地址。必要时点击「配置局域网防火墙」，允许 Windows 的管理员权限请求。规则只针对专用网络和同一子网；家庭网络若为公用网络，需要你在 Windows 设置中切换为专用网络。
5. iPad 的 SenPlayer / Filebar 中添加 **Jellyfin** 服务器，填入窗口显示的视频地址、账号与密码。
6. SenPlayer 的自定义弹幕 API 可填入窗口中显示的第二个地址。Filebar 可以尝试服务器弹幕或自定义弹幕地址；不同版本的自动加载行为需要在实际 iPad 上确认。

视频地址的格式为 `http://电脑局域网IP:8096`，弹幕 API 地址的格式为 `http://电脑局域网IP:9321/随机访问密钥`。请复制 GUI 中的实际地址，不要使用这里的占位文字。

## 影片与弹幕

- 「扫描媒体库」提交 Jellyfin 扫描，识别标题、年份、季与集号；弹幕插件默认自动匹配新影片。
- 「影片与弹幕」分页读取媒体库，支持按影片名、剧集名和文件路径搜索；留空显示全部。文件大小使用十进制 GB，码率同时显示 Mbps 和对应的 MB/s。
- 「搜索匹配弹幕」搜索在线作品、选择来源和对应集数，下载到视频旁的同名 XML；替换时保留 `.bak` 备份。
- 「刷新弹幕」提交选中电影或剧集的匹配刷新队列，完成时间取决于上游来源。
- 「导出 XML」读取已缓存的弹幕并选择导出位置。
- 「影片详情」打开 Jellyfin 网页，可修正媒体元数据与外挂字幕匹配。

弹幕 XML 会保存在视频同目录，需要该目录的写入权限。影片本身不被改写。自动匹配依赖清晰的标题、年份和集号；多剪辑版本可能需要在 iPad 调整弹幕延迟。没有对应在线弹幕的影片无法生成真实弹幕。

## 动漫多源搜索

在「影片与弹幕」点击「弹幕来源」，可启用 / 停用来源并添加自己的兼容 API，保存后下次搜索立即生效。

| 来源 | 默认状态 | 说明 |
|---|---|---|
| Animeko | 启用 | 通过 Bangumi 动漫目录搜索，并读取 Animeko 公益弹幕。目录有条目不代表每集都有弹幕。 |
| 巴哈姆特动画疯 | 启用 | 搜索、选集、下载弹幕；自动转换繁简体搜索词。 |
| 现有平台 | 启用 | 保留 Jellyfin Danmu 插件的 B 站、爱奇艺、优酷等来源。 |
| 弹弹play 官方 | 配置凭证后可用 | 在来源窗口填写自己的 AppId / AppSecret，按官方协议签名。未配置时显示提示，不阻塞其他来源。 |
| 自定义 API | 添加后启用 | 最多 5 个，格式为 `来源名称|API 根地址`，兼容弹弹play v2 协议。可填到访问密钥路径，或以 `/api/v2` 结尾。 |

所有启用的来源并发搜索、合并结果，各来源保留独立候选，避免不同版本混淆。默认只显示动漫及同名的相关候选；电脑搜索窗口可取消「只看动漫」，iPad 的默认过滤可在来源设置中修改。来源失败会单独显示状态，错误信息不会输出密钥。

新增来源同时用于电脑「搜索匹配弹幕」和 iPad 自定义弹幕 API，原 iPad 弹幕地址不变。Jellyfin 插件的「刷新弹幕」及自动匹配队列仍使用插件原有来源；新增源需要在电脑或 iPad 中搜索、核对季度和集数后加载。电脑手动关联后，SenPlayer 的 Jellyfin 弹幕接口可读取同名 XML。

外部弹幕请求遵循 Windows 系统代理；局域网视频和 Jellyfin 管理请求直连，不经过该代理。AppSecret 和自定义 API 配置使用 Windows 当前用户加密保存在本机。

实测例子及来源说明见 [动漫来源说明](docs/ANIME-SOURCES.md)。

## 启动、托盘与退出

在「启动与偏好」更改后点击「保存设置」。

| 设置 | 行为 |
|---|---|
| 开机启动 | 当前用户登录 Windows 后自动启动服务，窗口隐藏到系统托盘。关闭开关会删除本项目启动项。 |
| 手动打开程序时同时启动服务 | 双击启动器时自动运行 Jellyfin 和弹幕网关。默认关闭。 |
| 关闭窗口：缩小到托盘 | 右上角 × 隐藏窗口，服务继续运行。默认选项。 |
| 关闭窗口：停止服务并退出 | 右上角 × 先停止本项目的视频和弹幕服务，再退出程序。 |
| 托盘菜单：退出并停止服务 | 无论关闭偏好如何设置，都完全退出。 |

系统可能将托盘图标放在右下角的展开区域。双击图标恢复窗口；再次运行启动器也会恢复原窗口，不会运行多个实例。最小化按钮仍最小化到任务栏。

开机启动是**登录后启动**，不是未登录时运行的 Windows Service。账户注销后不保证继续服务。睡眠期间局域网播放会中断。

## 蓝光视频播放

默认「保留原画」禁止当前账号的视频转码，允许无损重新封装及音频转换。其他新建播放账号需要在 Jellyfin 中单独设置相应策略。若 iPad 不支持某个视频编码，原画模式可能无法播放；可以取消该选项允许转码，再配置 Jellyfin 硬件加速。

影片体积大不会使软件自动加速网络。建议电脑通过千兆网线连接路由器，iPad 使用信号良好的 5GHz / 6GHz Wi-Fi。在播放器中选择原画和足够的缓存。GUI 显示的影片码率不是实际网络测速，实际吞吐量和两款播放器的蓝光兼容性需要设备实测。

优先支持常见独立媒体文件（例如 MKV、MP4、M2TS）。蓝光 ISO 和 BDMV 完整目录的客户端播放能力不能由 HTTP Range 支持替代，需另行实测。

## 构建与验证

Windows .NET Framework 4.8，系统自带 C# 编译器；不需要安装 .NET SDK、Node.js 或 Python。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Test
```

构建前从托盘退出控制台，避免可执行文件被占用。自检需要正常 Windows 用户上下文以使用 DPAPI。真实集成测试运行 `bin/DanMuLAN.exe --integration-test`，在 `tests/output` 创建独立数据目录和合成视频，不读取现有 Videos 视频。报告在 `tests/output/self-test.txt` 与 `tests/output/integration-test.txt`。

## 目录与维护

| 目录 | 内容 |
|---|---|
| `src` | C# GUI、服务管理、弹幕网关与测试源代码 |
| `scripts` | 构建、组件安装、局域网防火墙配置 |
| `bin` | 已构建的控制台可执行文件 |
| `runtime/jellyfin` | Jellyfin 便携版及 FFmpeg |
| `downloads` | 已校验的离线组件包 |
| `data` | 设置、加密凭证、服务器数据库、缓存与日志 |
| `tests/output` | 验证报告与独立测试数据 |

改变端口前先停止服务，保存后更新 iPad 地址，并重新运行局域网防火墙配置。当前程序只停止它启动或核对过进程记录的 Jellyfin 实例，不会接管其他已安装服务器。

修改关闭选项立即生效。禁止视频转码的设置保存时若服务器正在运行会立即应用；服务器停止时保存则在下一次启动并连接有效账号后应用。
