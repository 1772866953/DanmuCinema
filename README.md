# 弹幕影院 DanmuCinema

程序采用 WPF 界面，整合 Jellyfin 视频服务与弹幕插件。视频由媒体服务器直接传输，安装包包含所需运行组件，无需另行下载服务器或插件。

## 下载与安装

前往 [GitHub Releases](https://github.com/1772866953/DanmuCinema/releases/latest)，下载 `DanmuCinema-Setup-1.0.8-win-x64.exe`。

- 系统要求：Windows 10 2004 及更新版本的 64 位系统，包括 Windows 11。
- 安装时可选择安装路径、设置管理员账号和密码、选择媒体目录与识别方式。媒体目录默认留空。
- 发布页同时提供 SHA-256 校验文件和对应源码包。

## 首次连接

1. 安装后打开程序，完成账号与媒体目录设置，启动服务。
2. 在“影片与弹幕”点击“扫描媒体库”，等待进度完成，列表会自动更新。
3. 在“连接设备”选择实际使用的局域网网卡地址，复制视频服务器地址。
4. 在支持 Jellyfin 的播放客户端中添加服务器，填写地址和账号、密码。电脑与客户端需要能够在局域网内互相访问。
5. 提前匹配并下载弹幕，按客户端支持的方式加载服务器弹幕或视频旁的 XML。支持自定义弹幕 API 的客户端，也可使用程序显示的弹幕地址。

视频地址通常为 `http://电脑局域网IP:8096`，本机弹幕接口地址通常为 `http://电脑局域网IP:9321/访问密钥`。两者由所选网卡和端口生成，是只读地址，请复制程序中的实际值。

连接受阻时可使用“配置局域网防火墙”，按 Windows 提示授予管理员权限。防火墙规则面向专用局域网，不应将服务端口直接开放到公网。

## 影片与弹幕

- 默认按文件夹浏览作品，进入文件夹后查看影片。支持子目录中的剧集、电影和动漫识别，也可手动调整媒体库识别方式。
- 支持名称、修改日期、大小等排序，文件大小以 MB 显示。搜索用于筛选，支持搜索历史及单条、全部删除。
- 支持复选框、全选、鼠标圈选与多选。鼠标侧键可前进、后退。
- 可以为单集、整季或已选影片重新选择弹幕来源，核对季度和集号后批量下载。
- XML 保存到视频旁的同名文件。替换时直接覆盖，不生成 BAK 备份。
- 下载任务显示进度，支持重试和取消。取消并清理任务会删除该任务对应的弹幕，请核对目标。
- 影片列表右键菜单支持删除弹幕、视频或整个文件夹。这些是实际删除操作。

程序在支持的播放请求中尝试提前准备弹幕。临时请求超时会取消本次请求并重试，重新发起播放也可再次尝试；有效缓存优先使用。首次获取仍可能等待，提前准备整季弹幕更方便。客户端是否自动加载新弹幕取决于其支持能力。

## 弹幕来源与匹配

在“影片与弹幕”的“管理接口”中启用来源。搜索会汇总已启用来源的结果；一个来源失败不会阻止其他来源返回结果。

| 来源 | 使用方式 |
| --- | --- |
| 弹弹play 官方 | 自行配置 AppId 和 AppSecret 后启用；自动匹配优先使用文件哈希识别 |
| Animeko | 动漫目录搜索与弹幕来源；存在作品条目不代表每集都有弹幕 |
| 巴哈姆特动画疯 | 动漫搜索、选集与弹幕下载 |
| 现有平台 | 使用 Jellyfin Danmu 插件提供的平台来源 |
| 自定义 API | 添加兼容弹弹play v2 协议的接口 |

官方文件哈希未命中时，程序会结合文件名、季度、集号和同目录已确认关联寻找候选。无法可靠判断时仍需要人工确认，不同剪辑版本也可能需要调整弹幕时间。

官方凭据保存在安装目录的 `config/dandanplay.json`，界面只保留启用复选框。填写自己的凭据即可，程序支持已有明文与本机加密配置：

```json
{"AppId":"你的 AppId","AppSecret":"你的 AppSecret"}
```


## 缓存 日志与后台运行

- **缓存**：首次成功获取后本地保存，下次优先读取有效缓存；按作品文件夹展示，支持右键删除、清理过期及全部清空。各类缓存共用有效期，可选一个月、三个月、半年、一年或长期。删除缓存不删除视频旁的 XML。
- **日志**：可设置最大保留天数，并删除全部日志。
- **启动与托盘**：可设置登录 Windows 后自动启动、手动启动时运行服务，以及关闭窗口时留在托盘或停止服务退出。主窗口按需创建并恢复上次大小，后台服务继续工作。
- **定时任务**：支持倒计时、指定时间和周一至周日的每周计划；日期与执行时间共同生效，到时操作默认休眠。托盘中继续计时，退出程序会取消计划。
- **界面**：支持 100% 和 120% 缩放，提供统一弹窗与过渡动画。
- **卸载**：可选择保留缓存和日志；账号与 API 配置会删除。卸载不会删除媒体目录或视频旁的弹幕。

## 播放条件

大体积视频的流畅度取决于网卡、路由器、无线连接和客户端解码能力，程序不会自动增加网络带宽。默认“保留原画”禁止视频转码，允许重新封装与音频转换；客户端不支持某些编码时，可按需要调整转码策略。

软件管理已有媒体，不提供视频资源。在线弹幕搜索与下载需要联网，来源覆盖范围和可用性由各服务决定。

## 开发与构建

| 目录 | 内容 |
| --- | --- |
| `development/src` | 服务管理、弹幕网关、匹配和缓存逻辑 |
| `development/desktop` | WPF 界面与交互 |
| `development/plugin` | 播放准备插件 |
| `development/installer` | Inno Setup 安装器与源码依赖清单 |
| `development/scripts` | 构建、打包及校验脚本 |
| `development/tests` | 功能与安装验证脚本 |
| `development/docs` | 第三方说明与许可证 |
| `packages` | 本地导出的安装包、对应源码与发布资料 |

程序编译使用 Windows .NET Framework 4.8 的系统 C# 编译器，不要求安装 .NET SDK。构建安装包还需要 Inno Setup 6.7 或更新版本、Python 3.9 或更新版本及 PowerShell 7.6 或更新版本。

```powershell
# 编译程序与播放准备插件
powershell.exe -NoProfile -ExecutionPolicy Bypass -File development/scripts/build.ps1 -ForInstaller

# 生成安装包；构建机器需准备脚本指定的离线组件与对应源码
pwsh -NoProfile -File development/scripts/build-installer.ps1 -Version 1.0.8 -IsccPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" -PythonPath python
```

编译输出位于 `development/bin/installer-app`。运行软件请使用安装包安装，仓库不维护个人运行环境；二进制运行组件、下载缓存和测试输出不提交到 Git。
