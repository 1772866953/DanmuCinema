# DanmuCinema 弹幕影院

Windows 局域网媒体服务与弹幕管理工具。电脑保存视频，播放客户端通过 Jellyfin 协议连接；程序负责媒体索引、弹幕匹配和下载。

[下载安装包](https://github.com/1772866953/DanmuCinema/releases/latest) · [构建说明](liquid-glass/README.md) · [第三方组件](liquid-glass/development/docs/THIRD-PARTY.md)

## 功能

- 媒体库：添加、扫描进度、目录浏览、搜索筛选、排序、多选、搜索历史、识别方式调整及媒体库删除。
- 弹幕：优先使用弹弹play文件哈希识别，再结合文件名、季度、集号及同目录记录匹配；支持多来源搜索、单集和整季预览下载。
- 播放准备：客户端请求播放时自动查找缺失弹幕。支持的播放流程会等待准备完成，具体加载行为取决于客户端。
- 下载管理：暂停、继续、重试、取消并清理。XML 与视频同目录同名，替换时直接覆盖。
- 缓存与日志：按作品管理缓存，统一设置有效期；设置日志保留天数、删除全部日志。
- 桌面设置：开机启动、托盘运行、窗口状态记忆、100% / 120% 缩放、倒计时、指定时间及每周计划。

## 关键技术

| 部分 | 实现 |
| --- | --- |
| 桌面界面 | Electron、React、TypeScript、Vite、liquid-glass-react、Motion |
| 业务核心 | C# / .NET Framework 4.8，通过标准输入输出管道与桌面进程通信 |
| 视频服务 | Jellyfin Server、弹幕插件及播放准备插件 |
| 识别与搜索 | 文件前 16 MiB 的 MD5、名称及集号解析、季度关联、别名回退、本地缓存 |
| 后台运行 | 关闭到托盘时销毁界面窗口，保留媒体服务与定时任务 |

## 安装与连接

1. 系统要求：Windows 10 2004 或更新版本、Windows 11，64 位；需要系统组件 .NET Framework 4.8。
2. 从 Release 下载 EXE。安装包包含桌面运行时、媒体服务和弹幕插件；源码包用于查阅和构建，普通使用无需下载。
3. 安装时设置路径、管理员账号、端口及媒体目录。媒体目录默认留空，也可安装后添加。
4. 启动服务，等待媒体库扫描完成。在播放客户端填写程序“连接设备”页面显示的地址及账号密码。

## 注意事项

- 公开包不含 API 凭据。使用弹弹play官方接口时，在安装目录 `config/dandanplay.json` 填写自己的配置，并启用对应来源：

  ```json
  {"AppId":"","AppSecret":""}
  ```

  文件识别及弹幕请求不需要 OAuth 回调地址。不要公开此配置文件、账号或运行数据。
- 视频保存在原目录。删除“媒体库”只移除库记录和索引；影片列表中的“删除视频”“删除整个文件夹”“删除弹幕”会删除对应文件。
- 动漫分类使用弹弹play目录结果。Jellyfin 的基础类型仍为剧集或电影，客户端是否单独显示动漫栏目由客户端决定。
- 在线弹幕需要联网，匹配覆盖与接口可用性取决于来源。文件未被收录时，哈希识别可能没有结果，可改用名称搜索或手动指定。
- 服务默认端口为 `8096` 和 `9321`。电脑与客户端需网络互通；传输速度取决于网络和设备，不提供视频资源。
- 升级保留原有配置。卸载可选择保留缓存和日志，账号与 API 配置会删除，媒体文件不会随卸载删除。
