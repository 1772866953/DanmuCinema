# DanmuCinema v1.2 使用说明

英文名称、可执行文件与启动脚本已统一为 DanmuCinema。首次从源码安装时运行 `scripts/install-components.ps1` 和 `scripts/build.ps1`，之后运行 `Start.cmd` 或 `bin/DanmuCinema.exe`。

根目录的 `DanmuCinema.lnk` 和 `启动弹幕影院.lnk` 提供带图标的启动入口，调用原 `Start.cmd`；程序、任务栏和托盘使用同款图标。构建时自动生成快捷方式。如果移动了项目目录，运行 `scripts/create-shortcuts.ps1` 更新快捷方式的路径。

## 智能搜索匹配

在本地影片列表选择一集并打开「搜索匹配弹幕」，默认自动开始查询。勾选「智能搜索匹配」时会清理字幕组、画质、编码和季集标签，并在未找到合适结果时尝试清理后的名称及短标题。每个来源最多尝试三个搜索词，共享 15 秒期限。

候选按名称相似度和季度排序。名称相似度达到阈值且已知季度相符时，自动推荐作品、读取集数，并按本地集号选集。相似度是文本匹配分数，不代表内容识别正确率；下载前仍须核对番剧、年份、季度及剪辑版本。低相似度或季度不明确的候选需要手动选择。iPad 的自定义弹幕接口同样使用智能查询与排序。

## 全部下载本季

匹配并选择作品后点击「全部下载本季」，程序读取同季本地文件并显示对应表。优先使用 Jellyfin 集号；缺失时识别 S02E03、EP03、结尾括号 (3) 或独立数字等文件名格式。

- 按实际集号关联，列表中的第 10 集不会因字典排序而对应到第 2 集。
- 无法识别、合并集、重复本地版本或重复在线集号会跳过，不按列表位置猜测。
- 可取消勾选部分集数；默认保留已有 XML。关闭「保留已有 XML」后，替换保留 `.bak`。
- 下载顺序执行，网络请求之间间隔一秒；单集失败不影响后续集数。
- 「停止下载」取消当前请求与后续任务，已成功下载的 XML 保留。
- 弹幕保存在对应视频旁；没有弹幕的响应不写入文件，视频本身不改写。

本功能下载当前本地季度对应的已选集数，不用于抓取来源的整个数据库。特殊篇、合并集或多个剪辑版本可用单集模式手动关联。

## 弹弹play 配置文件

来源窗口仅保留「弹弹play 官方 API」复选框。启动程序后生成 `config/dandanplay.json`，或复制 `config/dandanplay.example.json` 为该文件并填写官方分配的 AppId / AppSecret。修改后下一次请求读取，无需重启。

已有旧版 GUI 凭证会自动迁移到独立文件，迁移的密钥仍使用 Windows 当前用户加密。手动填写 AppSecret 时文件含有凭证，应只在本机保存。`config/dandanplay.json` 和备份均被 Git 忽略；仓库只提供空模板。

项目依旧需要官方有效接入凭证；未就绪时跳过该来源，不影响其他来源。
