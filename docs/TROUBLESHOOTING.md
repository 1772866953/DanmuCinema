# 影片能播放但没有弹幕

## SenPlayer 拖动进度条后弹幕清空再出现

直接加载视频旁的 XML 时，弹幕在屏幕上的位置和跳转后的恢复由 SenPlayer 决定。清空后从右侧重新进入，更像是播放器重建弹幕显示队列；尚未在 iPad 上复现，不能据此认定为网络重新下载。

完全连续的跳转效果需要播放器把目标时间之前、仍在显示期间的弹幕按已走过的时间恢复到屏幕中间。标准 XML 提供出现时间、类型、颜色与正文，不提供播放器的当前轨道与屏幕坐标；电脑端无法通过修改 XML 强制实现这种效果。

DanmuCinema 下载结果现在按出现时间稳定排序，包括单集、批量和自定义 API 返回结果。同秒弹幕保留原顺序，正文、颜色、位置类型与原始时间不变。这提高依赖时间顺序的客户端的跳转兼容性，不保证改变 SenPlayer 的清屏行为。

旧 XML 可在项目目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/optimize-danmu.ps1 -Path "视频旁的文件.xml"`，默认只检查。加 `-Apply` 才会替换，并保留带时间和随机标识的 `.before-sort-*.bak` 原文件备份。已排序文件不改写；视频不改写。替换后需在 iPad 重新载入弹幕文件，已导入的副本不会自动更新。

可先核对 SenPlayer 版本并更新：其 App Store 更新记录曾列出快进后弹幕不显示的修复。如果新版本加载已排序 XML 仍清屏后逐渐恢复，应向播放器开发者反馈「拖动进度条后恢复目标时间前仍应在屏幕内的弹幕」；如果空白持续很久或不再恢复，需要提供播放器版本、跳转前后时间及弹幕来源进一步定位。

## 骸骨骑士大人冒险中 S2 的实测结果

2026-10-06 检查发现：

- 12 个 MKV 已作为 Episode 入库，剧集名为「骸骨骑士大人冒险中S2」，各集标题为罗马字。
- 原控制台使用 Jellyfin SearchTerm，只搜索到各集标题，中文剧集名搜索返回 0。新版改为分页读取视频，再匹配影片名、剧集名和路径。
- 这批 Episode 的 IndexNumber / ParentIndexNumber 都为空，插件日志显示 Season Unknown 和自动队列 NullReferenceException，自动下载未生成 XML。
- SenPlayer 请求 `/api/danmu/{id}/raw` 时，因为视频旁没有同名 XML，返回 404。
- 插件手动搜索返回 `site_id`，集数返回 `cid`。新版支持这些字段，修复读取来源和下载弹幕的接口兼容问题。
- 用「骸骨骑士」及多个第二季名称查询，当前已启用的来源返回的相关作品都是 2022 年版本。尚未确认属于 S2 的可用来源；未将这些弹幕关联到 S2。

搜索 / 下载接口已实测：本地中文搜索返回 12 集；2022 年优酷候选返回 12 集，第 3 集下载到 437 条弹幕。这项下载只验证接口，并未写入视频目录。

完整结果见 `tests/output/example-verification.txt`。

2026-10-06 后续新增 Animeko / 巴哈姆特来源后，已成功找到 S2 的 2026 年候选，且第 3 集分别返回 9 / 544 条弹幕；上述「尚未确认属于 S2 的来源」仅适用于原来的平台来源。见 [动漫来源说明](ANIME-SOURCES.md)。

## 使用方式

1. 在「影片与弹幕」搜索本地影片并选择一行。
2. 点击「搜索匹配弹幕」。搜索词会去掉末尾的 S 季号，以发现不同名称的作品。
3. 核对候选的年份、季度及集数，再下载关联。总集数相同不代表季度相同。
4. 没有选择本地影片也能在线搜索；关联前需返回本地列表选择视频。

## 自动匹配所需的元数据

剧集目录宜按「剧名 / Season 02 / 剧名 S02E03.mkv」组织，并核对 Jellyfin 识别的剧名、季号和集号。当前项目未改名或移动现有视频。

修正目录或元数据可以帮助自动识别，但不能保证上游拥有该季度弹幕。源故障同样可能表现为空结果，具体原因需查看 `data/server-logs`。
