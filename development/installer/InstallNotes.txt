DanmuCinema 弹幕影院 · 离线安装包

支持 Windows 10 2004 或更新版本、Windows 11，64 位。
包含桌面程序、Jellyfin 视频服务、弹幕插件、播放准备插件和视频处理组件。
安装过程中不需要下载运行组件，不需要安装开发工具或其他插件。

安装向导会设置：安装路径、服务管理员账号及密码、媒体文件夹、局域网端口、开机启动和关闭到托盘。
管理员账号用于媒体服务，不是 Windows 账号。密码至少 8 位。
安装路径应为当前 Windows 用户可写的目录；默认安装到用户目录。
局域网访问仅放行 Windows 专用网络的本地子网，需要额外确认 Windows 管理员权限。

安装后启动程序，会自动启动视频及弹幕服务并扫描媒体目录。播放和弹幕查询可能需要网络。
官方弹幕接口的个人 AppId / AppSecret 不随通用安装包分发。安装时可选导入已有 dandanplay.json，也可安装后在 config/dandanplay.json 中配置。
其他已启用来源可直接使用。弹幕来源可用性取决于对应服务。

更新前请从托盘退出旧程序。更新会保留已有账号、媒体目录和设置。
卸载保留 data 和 config 下的个人数据，媒体目录及视频文件不会删除。
要重新创建管理员账号，请使用全新的安装目录；已有服务账号不会被安装器重设。

第三方组件的许可证、源码及构建说明随包安装于 licenses 目录。
